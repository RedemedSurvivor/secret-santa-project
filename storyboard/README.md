# Cousins' Christmas storyboard

Open [the editable storyboard](index.html) in a browser. Click a heading or description to edit it. Copy edits persist in that browser. Edit the HTML to commit shared revisions.

Try **Spin the wheel** for the 3.2-second preview, or **Reveal now** for a direct reveal. **Mango Lantern 47** is sample copy. The storyboard uses one fictional recipient and accepts any input.

The [HyperFrames motion study](motion/index.html) is a separate seekable composition for reviewing the spin and avatar landing. Run `npx hyperframes check` or `npx hyperframes preview` from the motion directory.

For the real exchange, collect preferred names, private reference photos or avatar descriptions, pronunciation if sound ever uses names, gift day, and budget. Share photos privately. Use random two-word and two-digit codes for the live exchange, with server-side validation and throttled attempts.

## Interactive demo

Open [the interactive demo](demo/index.html) in a browser and enter **Mango Lantern 47**. Enable sound to hear the typing cue, ratchet and chime. Move a mouse or drag a finger across the card to tilt it. The demo uses fictional data and includes reduced-motion and silent operation.

For the live exchange, use versioned browser-cached static assets and no-store responses for invite redemption and assignments. An independently controlled server should deliver secret codes privately, return only the caller's assignment, and give organizers only names and redemption status. The server and database operator remains inside the trust boundary.

## Njithi Cousins build (second pass)

Open [the second-pass demo](njithi/index.html). It replaces the interactive demo's look and keeps `demo/draw.mjs` as the draw engine. It has the handwritten opening, a large nameless wheel, a long drumroll, fireworks, a drawn portrait card with glare, a portrait builder and a host status view. Codes: **Mango Lantern 47** and **Chai Thunder 12**. All cousins in it are fictional.

Real roster, codes, assignments and family portraits stay out of this repository. The host view and the sealed-envelope server are demo only until the draw service is built.
