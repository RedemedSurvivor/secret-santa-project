Njithi Cousins Secret Santa Dispatcher

Send each cousin their own private link on WhatsApp. This page holds no links until you load the private file.

How to send

  1. Load private/invites.csv (made by node draw/build-invites.cjs private/roster.json). It stays on this device and is never uploaded.
  2. Type each phone number. 0712 345 678, +254 712… and 254712… all work.
  3. Tap Send: WhatsApp opens with the message ready. Press send in WhatsApp, then come back for the next cousin.
  4. Never forward a link to the wrong person: whoever opens a link sees that cousin’s match.
